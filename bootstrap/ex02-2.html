Including Bootstrap JS Plugins

bootstrap.bundle.min.js includes both Bootstrap's JavaScript and Popper.js (required for tooltips and popovers). bootstrap.min.js includes only Bootstrap's JavaScript — you must include Popper.js separately if you need tooltips or popovers.
