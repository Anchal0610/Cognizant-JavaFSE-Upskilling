Customizing Bootstrap with Sass

Override Variables Before Importing

Create a custom.scss file and override Bootstrap's default variables before importing the framework:

// Custom variable overrides
$primary: #ff5733;
$border-radius: 0.5rem;

// Import Bootstrap
@import "bootstrap/scss/bootstrap";
Compiled Result (Mockup)

After compiling, these custom values are applied throughout all Bootstrap components:

Bordered Element (custom 0.5rem radius)

Directory Structure
project/
├── node_modules/
│   └── bootstrap/
├── scss/
│   ├── custom.scss       <-- Your custom SCSS file
│   └── _variables.scss   <-- Optional partials
├── css/
│   └── custom.css        <-- Compiled output
├── index.html
└── package.json
Recompilation

Any time you change your SCSS variables or files, you need to recompile to regenerate the CSS:

sass scss/custom.scss css/custom.css

# Or watch for changes automatically:
sass --watch scss/custom.scss:css/custom.css
