Bootstrap is a free and open-source CSS framework directed at responsive, mobile-first front-end web development. It contains HTML, CSS, and JavaScript-based design templates for typography, forms, buttons, navigation, and other interface components.

The Bootstrap grid system uses a series of containers, rows, and columns to layout and align content. It is built with Flexbox and is fully responsive, allowing you to create complex layouts that automatically adjust across all screen sizes — from mobile phones to large desktops.

Bootstrap components are reusable, pre-styled UI elements such as navbars, cards, modals, alerts, badges, and carousels. They provide consistent styling and behavior out of the box, which speeds up development and ensures a uniform look across your project.
