Gradient Background

Hero Section

This hero section uses bg-dark bg-gradient to create a subtle gradient effect on the dark background.

Primary Gradient

Uses bg-primary bg-gradient text-white. The bg-gradient class adds a linear gradient overlay to background colors.

Success Gradient

Uses bg-success bg-gradient text-white. The gradient is applied as a CSS linear-gradient on top of the background color.

Note: The bg-gradient class applies background-image: var(--bs-gradient), which is a linear gradient from transparent to black (rgba(0,0,0,.15)), creating a subtle vignette effect on any background color utility.
