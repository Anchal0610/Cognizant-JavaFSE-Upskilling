Sass Setup Guide

Step 1: Initialize npm Project
npm init -y
Step 2: Install Bootstrap and Sass
npm install bootstrap@5.3.3 sass
Step 3: Create main.scss
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/mixins";

// Your custom styles here
body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
}
Step 4: Compile to CSS
sass main.scss custom.css

This compiles your main.scss file into a regular custom.css file that you can link in your HTML.

Step 5: Link the Compiled CSS
<link rel="stylesheet" href="custom.css">
Pro tip: Use sass --watch main.scss custom.css to automatically recompile whenever you make changes to your SCSS files.
