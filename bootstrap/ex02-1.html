Bootstrap Directory Structure

Directory Purpose
css/ Contains compiled CSS files including bootstrap.css, bootstrap.min.css, and optional theme variants (e.g., bootstrap-grid.css, bootstrap-reboot.css).
js/ Contains compiled JavaScript files including bootstrap.js, bootstrap.min.js, and bundle versions that include Popper.js for tooltips and popovers.
fonts/ Previously held Glyphicon icon fonts. As of Bootstrap 5, icon fonts are removed — use the separate Bootstrap Icons package instead.
Note: Icons (formerly in fonts/) are now a separate package at icons.getbootstrap.com.
