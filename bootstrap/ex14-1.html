Display Utilities

d-none — This div is always hidden.
d-md-block — Hidden on mobile (xs, sm), visible on md and above. Resize the browser to test.
d-lg-flex — Flex layout only on lg and above. Below lg it falls back to block.
d-print-block — This div is only visible when printing. It is hidden on screen.

Open the browser print preview (Ctrl+P) to see the d-print-block element.
