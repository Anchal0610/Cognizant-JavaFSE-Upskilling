Setting Up Bootstrap 5 via CDN

This is a jumbotron-style hero section built with Bootstrap's display and lead classes.

A CDN (Content Delivery Network) is a system of distributed servers that deliver web resources — like CSS and JS files — to users based on their geographic location. Using a CDN for Bootstrap means you don't need to download or host the files yourself; you simply link to them in your HTML.
